المرحلة 2 — Multi-token attention

هذه أهم نقطة.

Single-token attention الحالية ليست كافية لأنها لا تختبر فعليًا causal attention بين tokens مختلفة.

نفّذ reference attention بحيث عند position p:

Q(p)

يقارن مع:

K(0), K(1), ..., K(p)

فقط.

ويمنع:

K(p+1), K(p+2), ...

أي:

attention(p) =
softmax(
    Q(p) · K(0..p) / sqrt(head_dim)
)
· V(0..p)

مع الحفاظ على:

14 Q heads

2 KV heads

head_dim = 64

GQA repeat = 7

RoPE theta = 1e6

interleaved RoPE

causal masking
